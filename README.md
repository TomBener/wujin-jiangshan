# 无尽江山

一卷永远画不完的水墨山水长卷。山、树、舟、题诗、四季昼夜与古琴声，全部由代码在浏览器里实时生成——没有一张图片，没有一段录音。

**在线观看：** https://retompi.com/wujin-jiangshan/

## 玩法

- 拖动或滚轮展卷、回看；按古法，手卷自右向左展开
- 点天空放出仙鹤，点水面锦鲤跃出，点山林惊起飞鸟
- 点「听琴」：小船成为唱针，把身后山脊的高低实时读成古琴旋律
- 空格暂停，← → 前后移动；网址后加 `#卷号`（如 `#2046`）可重回同一卷

## 实现

- 单文件 `index.html`，Canvas 2D，无依赖（仅从 Google Fonts 加载马善政楷书与思源宋体）
- 山体：分形噪声山脊 + 沿轮廓层叠的墨色晕染、披麻皴 / 斧劈皴、飞白勾线、苔点，按季节叠加石青石绿或赭石
- 世界按卷号做确定性哈希生成，分块缓存，多层视差
- 声音：Web Audio，Karplus-Strong 模拟古琴拨弦（按音带滑音与吟猱）、泛音、散音与山寺钟声；四季换调依《礼记·月令》：春角、夏徵、秋商、冬羽
- 二十四节气与十二时辰随行程流转，题诗按季节与时辰从唐宋名篇中挑选
